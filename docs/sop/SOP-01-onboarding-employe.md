# SOP-01 — Onboarding d'un nouvel employé

**Version :** 1.0
**Date :** 2026-05-30
**Audience :** Employé (nouvel arrivant)
**Responsable :** L'employé lui-même, avec le soutien de son gestionnaire

---

## Objectif

Cette procédure guide tout nouvel employé dans la configuration de son compte WS Formation et la complétion de ses premières formations obligatoires.

---

## Déclencheur

Tu reçois un courriel d'invitation à la plateforme WS Formation lors de ton arrivée dans l'organisation.

---

## Étapes

### Étape 1 — Activer ton compte (Jour 1)

1. Ouvre le courriel d'invitation reçu de **noreply@ws-formation.vercel.app**
2. Clique sur le lien d'activation (valable 24 heures)
3. Crée ton mot de passe :
   - Minimum 8 caractères
   - Au moins 1 majuscule, 1 chiffre
4. Clique sur **"Créer mon compte"**
5. Tu arrives sur ton tableau de bord — ton profil est pré-rempli par ton gestionnaire

**Critère de succès :** Tu vois le tableau de bord avec ton nom affiché en haut à droite.

---

### Étape 2 — Vérifier ton profil (Jour 1)

1. Clique sur ton nom en haut à droite → **"Mon profil"**
2. Vérifie que les informations suivantes sont exactes :
   - Prénom et nom
   - Poste et département
   - Courriel
3. Si une information est incorrecte, contacte ton gestionnaire — tu ne peux pas modifier ton poste ou département toi-même

**Critère de succès :** Toutes tes informations sont correctes.

---

### Étape 3 — Activer la double authentification (optionnel mais recommandé)

La double authentification (MFA) protège ton compte si ton mot de passe est compromis.

1. Dans le menu de gauche, clique sur **"Sécurité"** (icône 🔐)
2. Clique sur **"Activer la double authentification"**
3. Sur ton téléphone, télécharge une application :
   - **Google Authenticator** (iOS / Android)
   - **Authy** (iOS / Android)
   - **Microsoft Authenticator** (iOS / Android)
4. Dans l'application, clique sur **"+"** ou **"Ajouter un compte"**
5. Scanne le code QR affiché sur la plateforme
6. Saisis le code à 6 chiffres affiché dans l'application
7. Clique sur **"Confirmer"**

À partir de maintenant, chaque connexion demandera ce code en plus de ton mot de passe.

> **Important :** Note le code secret quelque part en lieu sûr. Si tu perds ton téléphone, contacte ton administrateur pour réinitialiser le MFA.

---

### Étape 4 — Consulter tes formations assignées (Semaine 1)

1. Dans le menu de gauche, clique sur **"Mes formations"**
2. Tu verras la liste de toutes les formations qui te sont assignées
3. Pour chaque formation, tu vois :
   - Le titre et la description
   - La date limite de complétion
   - Ton avancement (0% au départ)
4. Commence par les formations marquées **"Priorité haute"** ou dont la date limite est la plus proche

---

### Étape 5 — Compléter une formation

1. Clique sur le titre de la formation pour l'ouvrir
2. Les leçons sont listées dans l'ordre — commence par la première
3. Lis ou visionne le contenu de chaque leçon
4. À la fin de chaque leçon, clique sur **"Marquer comme complété"**
5. Certaines leçons peuvent contenir un quiz — tu dois obtenir la note de passage pour continuer
6. Continue jusqu'à la dernière leçon

**Critère de succès :** La barre de progression affiche 100% et le statut passe à "Complété".

---

### Étape 6 — Obtenir ton certificat

Quand une formation est complétée à 100% :

1. Un certificat est généré automatiquement (dans les 5 minutes)
2. Va dans **"Mes certificats"** dans le menu de gauche
3. Tu verras le certificat avec :
   - Le nom de la formation
   - La date d'émission
   - La date d'expiration (généralement 1 an)
4. Tu peux télécharger ou imprimer ton certificat si nécessaire

---

## Points de contact

| Situation | Qui contacter |
|-----------|--------------|
| Problème d'activation du compte | Ton gestionnaire |
| Informations de profil incorrectes | Ton gestionnaire |
| Mot de passe oublié | Clique "Mot de passe oublié" sur la page de connexion |
| MFA perdu (téléphone perdu) | Administrateur système |
| Question sur une formation | Ton gestionnaire |
| Bug ou problème technique | Administrateur système |
